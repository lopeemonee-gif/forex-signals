# Crypto Signal Bot

Trading signal bot dengan Telegram alerts.

## Setup Local

```bash
pip install -r requirements.txt
python trader_crypto_tpsl.py
```

## Config

Edit `config_crypto.json`:
- Telegram bot token
- Chat ID
- TP/SL percentages

## Deploy Railway

1. Push to GitHub
2. Connect Railway to repo
3. Auto deploy

Bot running 24/7 di cloud.
